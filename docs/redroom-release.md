## 标题加载隔离修复 · 专用 Worker

本轮保留红帘、椅子、落地灯、镜头拖动与局部光晕的既有视觉设计，修复加载图被固有正方形尺寸撑大，以及 3D 准备阻塞主线程的问题。后备 WebP 现在绝对定位于景箱容器内，明确限制宽高并以 contain 完整显示；2048×1187 桌面实测图片和容器均为约1495×938。

`title-room.js` 留在主线程管理 DOM、导航、尺寸和输入；`title-worker.js` 通过 OffscreenCanvas 运行 `title-scene.js`，承担 GLB 解析、材质编译、纹理上传、阴影预热及实时绘制。加载提示采用阶段文字和材质预热数量，不再承诺字节百分比。异步编译、分帧材质预热和完整首帧完成后才切换至实时景箱。分辨率额外限制为720,000像素。游戏 renderer/composer 延迟到入场时创建，避免标题加载期间初始化第二套渲染器；入场会终止标题 Worker 并移除其画布。

GLB 请求限时20秒，可选 HDR 请求限时4秒，异步材质编译限时8秒；HDR 失败时仍使用实际场景直射光。主线程独立30秒看门狗可终止无法执行自身计时器的 Worker。不支持 OffscreenCanvas、Worker 出错或加载超时均保留完整后备图、游戏入口与重试；重试启动新 Worker，不刷新页面或存档。灯具射线拾取、真实灯光渐变、鼠标/触屏拖动、键盘及减少动态效果行为保留。

当前证据位于 `.impeccable/review/title-loading/worker/`。真实 Chromium/SwiftShader 回归覆盖2048×1187桌面、390×844触屏竖屏和844×390触屏横屏：加载图包含关系、等待时导航、故意阻塞 Worker 后的导航与超时恢复、可选 HDR 失败、实际 GLB 开关灯/射线拾取/拖动，以及加载中入场释放 Worker 均通过，页面异常数组为空。该回归未使用假渲染器。

1100×760冷启动记录从既有12.67秒可用、5.492秒主线程长任务，改善为本次5.51秒可用；本次单独性能记录仍有934毫秒初始模块执行任务，之后未记录标题准备长任务。完整横屏回归另有104毫秒准备期间任务，因此不承诺主线程完全无长任务。这些结果来自共享虚拟机开发服务器和软件渲染，不能换算为实体手机帧率或通用加载时限。

复现：启动 `npm run dev -- --port 5191` 后运行 `node scripts/title-worker-regression.mjs`；单独性能采样运行 `NAME=title-worker-current node scripts/title-load-profile.mjs`，输出至 `.impeccable/review/title-atmosphere/title-worker-current.json`。本轮保留的性能样本为 `title-loading/worker/performance.json`。
